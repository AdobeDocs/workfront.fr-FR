# Présentation des projets Adobe Creative Cloud

Vous pouvez accéder à vos projets Workfront directement depuis Adobe Photoshop, Illustrator et InDesign. Dans le panneau Projets situé sur le côté gauche de la fenêtre de l’application Creative Cloud, vous pouvez ouvrir, modifier et enregistrer des documents dans un projet Workfront sans quitter l’application. Vous pouvez également enregistrer de nouveaux fichiers directement dans un projet Workfront.

Seuls les projets qui utilisent l’espace de stockage Adobe dans le cloud apparaissent dans le panneau Projets à côté de vos autres projets Creative Cloud. Le panneau reflète la structure de dossiers des documents dans Workfront.

Lorsque vous enregistrez un document comportant un workflow d’approbation, Workfront crée une version et conserve l’historique d’approbation. Lorsque vous enregistrez un document qui ne comporte pas de workflow d’approbation, Workfront met à jour la dernière version.

## Conditions préalables

* Votre organisation doit utiliser une version de Workfront prenant en charge l’espace de stockage dans le cloud Adobe.
* Workfront et Photoshop, Illustrator ou InDesign doivent être autorisés dans la même organisation Adobe Identity Management System (IMS).


## Actions disponibles à partir du panneau Projets dans Photoshop, Illustrator ou InDesign

* Ouvrez des dossiers et des documents de projet Workfront directement dans Photoshop, Illustrator ou InDesign. Tous les projets Workfront auxquels vous avez accès s’affichent dans le panneau Projets .
* Modifiez un fichier et réenregistrez vos modifications dans le projet Workfront.

Pour plus d’informations, voir [Utiliser des documents Workfront dans les applications Creative Cloud](/help/quicksilver/documents/adobe-creative-cloud-projects/use-wf-documents-in-cc-apps.md).

>[!NOTE]
>
>Les projets de stockage Workfront hérités ne sont pas pris en charge dans le panneau Projets .

## Intégrations connexes

Vous pouvez également utiliser Adobe Cloud Drive pour gérer les fichiers Workfront et enregistrer automatiquement les modifications apportées aux documents dans Workfront. Pour plus d’informations, consultez [Présentation d’Adobe Cloud Drive](/help/quicksilver/documents/adobe-cloud-drive/adobe-cloud-drive-overview.md).
