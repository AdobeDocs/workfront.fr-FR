# Activité de la version du premier trimestre 2027 pour les fonctionnalités à disponibilité limitée d’Adobe Workfront

Cet article décrit la disponibilité limitée des fonctionnalités de Workfront publiées au cours du premier trimestre de 2027.

<!--keep the sentence below for all future quarterly release pages-->

Pour obtenir une liste de toutes les fonctionnalités de disponibilité limitée publiées pour Adobe Workfront, consultez l’activité de mise à jour des fonctionnalités de disponibilité limitée d’Adobe Workfront : index des articles [&#128279;](/help/quicksilver/product-announcements/product-releases/limited-availability-release-activity/limited-availability-release-activity-article-index.md).

## Notes de mise à jour pour les fonctionnalités à disponibilité limitée

Cette section comprend les notes de mise à jour relatives à la nouvelle fonctionnalité .

### Possibilité de développer ou réduire tous les groupes

>[!NOTE]
>
>Date de publication de la production : 27 octobre 2026

Vous pouvez désormais développer ou réduire tous les regroupements dans une liste améliorée à l’aide de l’icône de flèche en haut de la première colonne. Cela inclut les rapports chronologiques.

Auparavant, vous pouviez uniquement développer ou réduire tous les groupes dans les paramètres de regroupement.

Pour plus d’informations sur les listes améliorées, voir [Utiliser des listes améliorées](/help/quicksilver/workfront-basics/navigate-workfront/use-lists/enhanced-lists.md).

### Afficher la sélection sur les rapports chronologiques

>[!NOTE]
>
>Date de publication de la production : 27 octobre 2026

L&#39;expérience de création d&#39;une nouvelle vue dans un rapport chronologique a été rationalisée, de sorte que vous n&#39;avez plus à sélectionner un type de vue si un seul type de vue est disponible.

### Épingler la colonne des totaux dans les rapports chronologiques

>[!NOTE]
>
>Date de publication de la production : 27 octobre 2026

Vous pouvez maintenant épingler la colonne **Total** afin qu’elle reste visible à droite d’un rapport temporel.

Cette fonctionnalité peut également être disponible sur d’autres écrans qui utilisent une vue de matrice, comme les plans de dotation en personnel.
