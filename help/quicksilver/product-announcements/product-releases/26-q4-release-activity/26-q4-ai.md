# Améliorations de l’IA au quatrième trimestre 2026

Cette page décrit les améliorations apportées à l’IA dans l’environnement de Prévisualisation depuis le quatrième trimestre 2026. Ces améliorations seront rendues disponibles comme indiqué, dans l’environnement de production.

Pour obtenir la liste de toutes les modifications disponibles à ce stade du cycle de publication du quatrième trimestre 2026, voir [présentation de la version du quatrième trimestre 2026](/help/quicksilver/product-announcements/product-releases/26-q4-release-activity/26-q4-release-overview.md).

## Nouveaux outils d’approbation disponibles dans le connecteur MCP Workfront

>[!NOTE]
>
>Aperçu : 30 juillet 2026>Version rapide de production : 13 août 2026>Production pour tous : 15 octobre 2026

Pour étendre les fonctionnalités du connecteur MCP Workfront, nous avons ajouté les nouveaux outils suivants :

* Ajouter un chemin d’accès à l’approbation
* Supprimer le chemin de l’approbation
* Ajouter une étape au chemin d’accès
* Supprimer l’étape du chemin
* Réorganiser les étapes dans le chemin

En outre, les outils suivants ont été étendus pour prendre en charge les chemins d’approbation parallèles :

* Obtenir les informations sur le workflow d’approbation
* Créer ou mettre à jour un workflow d’approbation
* Créer une approbation à partir d’un modèle

Pour plus d’informations, voir [Outils de serveur Adobe Workfront MCP](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).

## Outils de carte disponibles dans le connecteur MCP Workfront

>[!NOTE]
>
>Aperçu : 30 juillet 2026>Version rapide de production : 13 août 2026>Production pour tous : 15 octobre 2026

Pour étendre les fonctionnalités du connecteur MCP Workfront, nous avons ajouté les outils suivants pour travailler avec les tableaux :

* Obtenir le panorama
* Obtenir la carte
* Créer un panorama
* Créer une carte
* Mettre à jour la carte
* Carte Connect
* Créer une balise de panorama
* Créer, mettre à jour ou supprimer des éléments de la liste de contrôle
* Créer, mettre à jour ou supprimer des colonnes du panorama

Pour plus d’informations, voir [Outils de serveur Adobe Workfront MCP](/help/quicksilver/workfront-basics/workfront-mcp-server/workfront-mcp-server-tools.md).
