# Améliorations de l’IA pour le premier trimestre 2027

Cette page décrit les améliorations apportées à l’IA de l’environnement de Prévisualisation dans la version du premier trimestre 2027. Ces améliorations seront rendues disponibles comme indiqué, dans l’environnement de production.

Pour obtenir la liste de toutes les modifications disponibles à ce stade du cycle de publication de la version du premier trimestre 2027, voir [Présentation de la version du premier trimestre 2027](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## Jeux d’outils du serveur MCP Workfront

>[!NOTE]
>
>Aperçu : 21 octobre 2026
>Version rapide de production : 12 novembre 2026
>Production pour tous : 21 janvier 2027

Pour faciliter le contrôle des fonctionnalités Workfront auxquelles un client d’IA peut accéder, nous avons ajouté des ensembles d’outils au serveur MCP Workfront. Vous pouvez désormais limiter le catalogue MCP aux fonctionnalités dont votre client a besoin au lieu d’exposer la liste complète des outils autorisés. Les ensembles d’outils disponibles comprennent `core`, `comment-stream`, `planning` et `approvals`.

La disponibilité des outils reflète désormais plus clairement les droits sur les produits. Les clients disposant d’une licence uniquement pour Workfront Planning voient Outils de planification, les clients disposant d’une licence uniquement pour Workfront Workflow voient Outils de workflow et les clients disposant d’une licence pour les deux ensembles voient les deux ensembles.

Pour plus d’informations, voir [Configuration du serveur MCP Adobe Workfront](/help/quicksilver/workfront-basics/workfront-mcp-server/configure-workfront-mcp-server.md) et [Utilisation du serveur MCP Adobe Workfront](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md).
