# Améliorations des documents du premier trimestre 2027

Cette page décrit les améliorations apportées aux documents avec la version du premier trimestre 2027 dans l’environnement Aperçu. Ces améliorations seront rendues disponibles comme indiqué, dans l’environnement de production.

Pour obtenir la liste de toutes les modifications disponibles à ce stade du cycle de publication du premier trimestre 2027, consultez [Aperçu de la version du premier trimestre 2027](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## Nouvelles fonctionnalités d’Adobe Cloud Drive v1.2.0

>[!NOTE]
>
>Aperçu : 25 novembre 2026
>Version rapide de production : 25 novembre 2026
>Production pour tous : 25 novembre 2026
>[!BADGE Version simultanée]{type=Neutral}
>[!BADGE Workflow Ultimate]{type=Informative}

Adobe Cloud Drive v1.2.0 introduit de nouvelles façons de télécharger des fichiers, de gérer la synchronisation et d’utiliser votre contenu cloud :

* **Charger vers le cloud (chargement direct) :** cliquez avec le bouton droit de la souris sur un fichier dans le Finder ou l’Explorateur de fichiers pour le charger directement dans un projet de l’espace de stockage Adobe dans le cloud, sans le copier au préalable dans le dossier Adobe Cloud Drive. Surveillez la progression dans la section Chargement direct de l’activité de synchronisation.
* **Suspendre et reprendre la synchronisation :** Suspendre Adobe Cloud Drive en cas de connexion lente ou limitée, puis reprendre lorsque vous êtes prêt.
* **Historique des versions :** Parcourez les versions cloud enregistrées d’un fichier, modifiez les noms et descriptions des versions, puis revenez à une version antérieure.
* **Gérer le stockage local :** surveiller l&#39;utilisation du disque local, définir une limite de stockage et afficher les fichiers marqués comme Toujours sur cet appareil.
* **Activité de synchronisation :** passez en revue les chargements, téléchargements et modifications récents, et identifiez les éléments qui n’ont pas pu être synchronisés.
* **Ouvrir dans Workfront :** ouvrir l’emplacement Workfront d’un élément directement à partir du Finder, de l’Explorateur de fichiers ou de l’activité de synchronisation.

Pour plus d&#39;informations, voir [Utilisation d&#39;Adobe Cloud Drive](/help/quicksilver/documents/adobe-cloud-drive/use-adobe-cloud-drive.md) et [Dépannage d&#39;Adobe Cloud Drive](/help/quicksilver/documents/adobe-cloud-drive/troubleshoot-adobe-cloud-drive.md).

## Configuration des notifications électroniques de révision et d’approbation unifiées


>[!NOTE]
>
>Aperçu : 5 novembre 2026
>Version rapide de production : 12 novembre 2026
>Production pour tous : 21 janvier 2027

Vous pouvez désormais configurer des notifications électroniques de révision et d’approbation unifiées. Workfront a toujours envoyé ces e-mails, mais vous ne pouviez pas les configurer jusqu’à présent. Il existe désormais 18 notifications regroupées en tant qu’Approbations unifiées et actives par défaut. Les administrateurs Workfront peuvent les activer ou les désactiver pour tous les utilisateurs dans la configuration et les utilisateurs peuvent les gérer dans leurs profils.

Dans le cadre de cette mise à jour, l’objet des e-mails pour ces notifications est légèrement modifié. Les objets s’affichent désormais avec le résultat, par exemple « Votre approbation est nécessaire le {Document} ». Les notifications sur le résultat global d’une approbation commencent par « Décision finale : » afin que vous puissiez les distinguer de la décision d’un approbateur individuel.

Pour plus d’informations, voir [Configurer les notifications d’événements pour tous les utilisateurs et utilisatrices du système](/help/quicksilver/administration-and-setup/manage-workfront/emails/configure-event-notifications-for-everyone-in-the-system.md).
