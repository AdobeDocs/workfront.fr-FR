# Améliorations des documents du premier trimestre 2027

Cette page décrit les améliorations apportées aux documents avec la version du premier trimestre 2027 dans l’environnement Aperçu. Ces améliorations seront rendues disponibles comme indiqué, dans l’environnement de production.

Pour obtenir la liste de toutes les modifications disponibles à ce stade du cycle de publication de la version du premier trimestre 2027, voir [Présentation de la version du premier trimestre 2027](/help/quicksilver/product-announcements/product-releases/27-q1-release-activity/27-q1-release-overview.md).

## Configuration des notifications électroniques de révision et d’approbation unifiées

>[!IMPORTANT]
>
>Cette fonctionnalité est temporairement indisponible dans l’environnement de Prévisualisation.


<!--
>[!NOTE]
>
>Preview: October 29, 2026
>Production fast release: November 12, 2026
>Production for everyone: January 21, 2027

-->

Vous pouvez désormais configurer des notifications électroniques de révision et d’approbation unifiées. Workfront a toujours envoyé ces e-mails, mais vous ne pouviez pas les configurer jusqu’à présent. Il existe désormais 18 notifications regroupées en tant qu’Approbations unifiées et actives par défaut. Les administrateurs Workfront peuvent les activer ou les désactiver pour tous les utilisateurs dans la configuration et les utilisateurs peuvent les gérer dans leurs profils.

Dans le cadre de cette mise à jour, l’objet des e-mails pour ces notifications est légèrement modifié. Les lignes d’objet indiquent désormais le résultat, par exemple « Votre approbation est nécessaire le {Document} ». Les notifications sur le résultat global d’une approbation commencent par « Décision finale : » afin que vous puissiez les distinguer de la décision d’un approbateur individuel.

Pour plus d’informations, voir [Configurer les notifications d’événements pour tous les utilisateurs et utilisatrices du système](/help/quicksilver/administration-and-setup/manage-workfront/emails/configure-event-notifications-for-everyone-in-the-system.md).
