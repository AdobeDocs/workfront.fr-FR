# [!DNL Adobe Workfront] pour [!DNL Mobile Device Management] (MDM)

{{mobile-maintenance-mode}}

Adobe [!DNL Workfront] s’est associé à des plateformes [!DNL Mobile Device Management] (MDM) pour offrir aux organisations une expérience mobile plus sécurisée et contrôlée. L’application mobile [!DNL Workfront] est disponible sur les plateformes de gestion des appareils mobiles suivantes :

## Intune

L’application mobile Workfront est désormais disponible dans l’App Store [!DNL Microsoft Intune]. Votre administrateur Workfront peut affecter l&#39;application à votre appareil via Intune.

* iOS
* Android

Votre instance Workfront doit se trouver sur Adobe Identity Management System (IMS).
