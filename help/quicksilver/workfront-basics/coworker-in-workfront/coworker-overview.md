# Présentation de CX Enterprise Coworker dans Workfront

>[!IMPORTANT]
>
>CX Enterprise Coworker n’est actuellement pas disponible pour les organisations des secteurs de la santé, de la finance ou de certains autres secteurs qui disposent de données sensibles. AI Assistant est disponible pour ces organisations. Pour plus d’informations, consultez [Aperçu de l’assistant AI](/help/quicksilver/workfront-basics/ai-assistant/ai-assistant-overview.md).

Le CX Enterprise Coworker Chat est une interface de conversation qui permet d’effectuer le travail. Il est désormais intégré à Workfront. Vous décrivez un objectif en langage clair, puis un collègue planifie le travail, l’exécute dans Workfront ou sur l’ensemble de vos systèmes Adobe et connectés, valide les résultats et vous renvoie le travail terminé pour approbation&#x200B;

Aujourd’hui, tout ce sur quoi repose votre équipe dans l’assistant d’IA continue de fonctionner, mais dispose désormais de fonctionnalités plus puissantes de bout en bout, disponibles dans une nouvelle expérience en plein écran et dans le panneau de droite de Workfront.

Coworker respecte les contrôles d’accès au niveau de Workfront existants de votre entreprise. Les utilisateurs peuvent uniquement effectuer des actions qu’ils sont déjà autorisés à effectuer dans Workfront. Par défaut, Coworker dispose d’un accès en lecture seule et les administrateurs système contrôlent quand les utilisateurs ont un accès en écriture.

Coworker fait partie de l’écosystème Adobe et ne se limite pas à Workfront.

Pour plus d’informations sur Coworker et ses fonctionnalités, consultez [Présentation du chat Adobe CX Enterprise Coworker](https://experienceleague.adobe.com/en/docs/coworker/content/chat/overview).

Pour plus d&#39;informations sur l&#39;utilisation de Coworker dans Workfront, voir [Utiliser CX Enterprise Coworker dans Workfront](/help/quicksilver/workfront-basics/coworker-in-workfront/use-coworker-in-workfront.md).

Pour connaître les compétences disponibles dans Coworker in Workfront, consultez [Compétences Workfront dans CX Enterprise Coworker](/help/quicksilver/workfront-basics/coworker-in-workfront/coworker-skills.md).

Pour obtenir un exemple d&#39;invites pour un collègue dans Workfront, consultez les invites dans l&#39;article [Utiliser le serveur MCP Adobe Workfront](/help/quicksilver/workfront-basics/workfront-mcp-server/use-workfront-mcp-server.md).

CX Enterprise Coworker sous Workfront est également disponible pour les fonctionnalités Workfront suivantes :

* Planification de Workfront. Pour plus d’informations, consultez [Présentation d’Adobe Workfront Planning CX Enterprise Coworker](/help/quicksilver/planning/general/planning-cx-coworker-overview.md)
* Espace d’idéation dans Workfront Planning. Cette version est actuellement en version bêta. Pour plus d&#39;informations, consultez [Prise en main de l&#39;espace d&#39;idéation pour Adobe Workfront Planning](/help/quicksilver/planning/ideation/get-started-with-planning-ideation.md)
